# # Wordly Dictionary

An interactive dictionary web application where users can search for words, listen to pronunciations, and save their favorites.

## Live Demo
[View Live Application](https://kahutrina77-code.github.io/wordly-dictionary/)

## Features

- **Search Words**: Look up any English word and get detailed definitions
- **Audio Pronunciation**: Listen to how words are pronounced
- **Multiple Definitions**: See different meanings and parts of speech
- **Example Sentences**: Learn how words are used in context
- **Synonyms**: Discover related words with clickable tags
- **Save Words**: Keep a list of your favorite words for quick access

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- [Free Dictionary API](https://dictionaryapi.dev/)

## How to Use

1. Type a word in the search box
2. Click "Search" or press Enter
3. View definitions, examples, and synonyms
4. Click the audio button to hear pronunciation
5. Save words you want to remember
6. Click on synonyms to search for related words

## Installation

1. Clone this repository:
```bash
git clone https://github.com/kahutrina77-code/wordly-dictionary.git
```

2. Open `index.html` in your web browser

That's it! No installation or setup required.
